# Preprocessing

An Elixir interface to `epp` (Erlang Preprocessor), mainly for extracting
macros and records.

## Installation

If [available in Hex](https://hex.pm/docs/publish), the package can be installed
by adding `preprocessing` to your list of dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:preprocessing, "~> 0.1.0"}
  ]
end
```

Documentation can be generated with [ExDoc](https://github.com/elixir-lang/ex_doc)
